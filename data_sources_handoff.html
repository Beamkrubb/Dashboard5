เป้าหมาย: สร้าง interactive dashboard เกษตรรายจังหวัดของไทย (77 จังหวัด) ที่เชื่อมผลผลิต ราคา ต้นทุน ชลประทาน ความเหมาะสมของดิน ภัยพิบัติ และฝน เข้ากับแผนที่ขอบเขตจังหวัด ขั้นตอนที่แนะนำ: 1) ดาวน์โหลดไฟล์จากลิงก์ "แหล่งหลัก" ของแต่ละชุด (ถ้าสถานะเป็น "ใช้แหล่งทดแทน" ให้ใช้รายการ "แหล่งทดแทน") 2) แปลงทุกตารางเป็นรูปแบบ long/tidy ตามสคีมาด้านล่าง เก็บไว้ที่ data/clean/*.csv 3) ทำตารางอ้างอิงจังหวัด (province_lookup.csv) จาก GeoJSON แล้ว join ทุกชุดด้วย pro_code 4) สร้าง dashboard เป็นไฟล์ HTML เดียว (แผนที่ choropleth + กราฟแนวโน้ม + ตัวกรองปี/พืช/จังหวัด) 5) อัปเดตช่อง "สถานะ" และ "หมายเหตุ" ในไฟล์นี้เมื่อพบปัญหาใหม่

ภาพรวมชุดข้อมูล

ข้อตกลงร่วมในการเตรียมข้อมูล

• ปี: แหล่งไทยส่วนใหญ่ใช้ พ.ศ. → ค.ศ. = พ.ศ. − 543 (2550–2562 = 2007–2019). ข้อมูลพืชบางชนิดเป็น "ปีเพาะปลูก" (เช่น 2562/63) ให้เก็บทั้ง crop_year_label และ year_ce (ปีเริ่ม) • จังหวัด: ใช้ pro_code (รหัส 2 หลักตามกรมการปกครอง) เป็น key หลัก. ทำ mapping ชื่อไทย/อังกฤษ เพราะแต่ละแหล่งสะกดไม่เหมือนกัน (เช่น "กรุงเทพมหานคร" / "กรุงเทพฯ", "บึงกาฬ" ตั้งปี 2554 จึงไม่มีข้อมูลก่อนหน้า — ปี 2550–2553 จะมี 76 จังหวัด) • หน่วย: เนื้อที่ = ไร่ (1 ไร่ = 0.16 เฮกตาร์), ผลผลิต = ตัน, ผลผลิตต่อไร่ = กก./ไร่, ราคา = บาท/กก., ต้นทุน = บาท/ไร่ หรือ บาท/กก., ฝน = มม. • ไฟล์ CSV ภาษาไทยอาจเป็น UTF-8 (มี BOM) หรือ TIS-620/cp874 — ลองอ่านทั้งสองแบบ • metadata ใน catalog หลายชุดระบุ "ปีล่าสุด" ไม่ตรงกับไฟล์จริง — เชื่อข้อมูลในไฟล์ ไม่ใช่ metadata • เก็บ source_id และ source_url ทุกแถว เพื่อให้ dashboard แสดงที่มาได้

ข้อจำกัดที่พบระหว่างตรวจสอบ

• data.go.th: หน้า dataset ส่วนใหญ่แสดงลิงก์ดาวน์โหลดเป็น template ที่ยังไม่ render (${cur_meta...}) เมื่อดึงอัตโนมัติ และ API package_search ใช้ได้ไม่สม่ำเสมอ → เปิดผ่านเบราว์เซอร์แล้วกดดาวน์โหลดเอง • ชุดข้อมูลบน data.go.th จำนวนมากเป็นของ "สำนักงานจังหวัด" รายจังหวัด ไม่ใช่ระดับประเทศ — อย่านำมาต่อกันโดยไม่ตรวจความสอดคล้อง • catalog.oae.go.th บล็อกการดึงหน้าที่ 2+ ของหมวดและ API ด้วย robots.txt → ต้องเปิดด้วยเบราว์เซอร์เพื่อดูรายการครบ (หมวดผลผลิตมี 70 ชุด, ราคา 35 ชุด) • data.tmd.go.th บล็อกการดึงอัตโนมัติ และต้องลงทะเบียนเพื่อรับ uid/ukey • ระบบ disaster.doae.go.th ต้องล็อกอินด้วย ThaiD จึงไม่ใช่ open data โดยตรง
